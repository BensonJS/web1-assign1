Five tags I have learned:

The Header tag.
The Header tag can be used to create a header for a section or the entire page. For example, the header for thhis page would be Notes on my knowledge of HTML TAGS
The Comment tag.
My favourite tag would probably be the comment tag that can be used to add notes or explanations within the HTML code that will not be shown on your website. How to use it would putting in < !-- -- > on the HTML code.
The Image tag.
The Image tag, < img > , can be used to insert images onto your website. but it would need two other tags to help, the < src= > is the help find a path to the image and the < alt= > is to describe the image in case the image does not load and for screen readers.
The Link tag.
The link tag or also known as the anchor tag, < a > , is used to create links to other web pages or resources. It would need the < href= > to destination URL of the link.
The Paragraph tag.
The Paragraph tag, < p > , is simple. It's a paragraph tag to be used to define a paragraph of text on the webpage.
